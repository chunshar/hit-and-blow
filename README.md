# hit-and-blow

ブラウザで遊べるヒット & ブローゲームです。CPUが出題者となって4桁の数字を決め、プレイヤーがそれを推理して当てます。

## 遊び方

1. CPUが0〜9の数字から重複なしで4桁の数字をランダムに決めます(0から始まってもOK)。
2. プレイヤーは4桁の数字を入力して回答します。
3. 回答するたびに、以下の判定が表示されます。
   - **Hit**: 数字と桁の位置が両方とも合っている数の個数
   - **Blow**: 数字は合っているが、位置が違う数の個数
4. 4桁すべてがHitになったら正解です。何回で当てられたかが表示されます。
5. 「新しいゲーム」ボタンでいつでも数字を引き直して再挑戦できます。

## ファイル構成

メンテナンスしやすいように役割ごとにファイルを分割しています。

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面のマークアップ(入力フォーム・履歴テーブル・勝利モーダルなど) |
| `style.css` | 見た目のスタイル・アニメーション |
| `script.js` | ゲームロジック(数字生成・判定・入力制御・状態管理) |

## 遊び方(起動方法)

`index.html` をブラウザで直接開くか、簡易サーバーを立てて開いてください。

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/index.html` にアクセスしてください。
